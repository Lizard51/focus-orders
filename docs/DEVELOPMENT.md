# Разработка и сборка

Для обычного пользователя достаточно [установщика](https://github.com/Lizard51/focus-orders/releases/latest). Эти команды нужны для работы с исходниками.

## Требования

- Node.js 24 и npm.
- Windows x64 для локальной сборки и Electron-проверок Windows-приложения.
- Git для получения исходников; интернет для первоначальной загрузки зависимостей и встроенного Electron.

```powershell
git clone https://github.com/Lizard51/focus-orders.git
cd focus-orders
npm ci
node node_modules/electron/install.js
npm start
```

Движок также загружается автоматически при первом обращении к Electron. Команда `install.js` позволяет завершить загрузку явно.

## Проверки

```powershell
npm test
npm run check
npm run format:check
npm run test:delete
npm run test:desktop
npm run test:ui
```

`npm test` — 25 тестов поведения хранилища; `check` — синтаксис, CSP и неизменность согласованных тестов из `tests/frozen-manifest.json`; `format:check` — читаемый единый стиль исходников. GitHub Actions запускает эти проверки на чистом runner. `npm run format` форматирует production-код и CJS-скрипты, замороженные тесты не изменяет.

Electron-проверки используют отдельные демонстрационные базы в `evidence/`, не обычный каталог пользователя. Они проверяют вкладки, ввод, шаблоны, архив, копии и перезапуск. Системные диалоги открытия/сохранения файла в общем E2E получают подставленный тестовый путь, а реальные чтение и запись выполняются на диске. `test:delete` отдельно проверяет оба статуса, отмену, вкладки и копию перед удалением.

Для проверки упакованной версии:

```powershell
$env:FOCUS_EXECUTABLE = (Resolve-Path 'release/win-unpacked/Фокус — Заказы.exe').Path
npm run test:delete
Remove-Item Env:FOCUS_EXECUTABLE
```

В ограниченной среде запуск Electron и первоначальная загрузка могут требовать отдельного разрешения. Проект не содержит отдельного TypeScript typecheck или lint; `check` не заменяет их.

## Установщик

```powershell
npm run build
```

Результаты: `release/Focus-Orders-Setup-<version>.exe` и `release/win-unpacked/`. NSIS создаёт ярлыки на рабочем столе и в меню «Пуск». Build не публикует файлы автоматически. Каталог `release` не входит в Git; установщик распространяется через GitHub Releases вместе с SHA-256.

Значок уже включён в репозиторий. Для его повторной генерации `node scripts/prepare-icon.cjs` использует headless Microsoft Edge на машине разработчика. Получателю Edge, Python и Node.js не нужны — встроенный движок включён в установщик.

Скрипт `test-install.ps1` проверяет установку в отдельную папку и затем убирает только тестовую установку/ярлыки. Он отказывается работать при уже существующей установке или одноимённых ярлыках. Не запускайте его вместо обычного обновления программы.

## Изменение поведения

Сначала добавьте тест требуемого поведения и проверьте ожидаемое падение, затем реализуйте изменение. Не ослабляйте существующие тесты ради успешного прогона. Если меняется согласованный контракт, обновите манифест и документацию намеренно, с объяснением в коммите.
