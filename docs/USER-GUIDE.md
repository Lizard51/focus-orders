# Фокус — Заказы: начало работы

Скачайте [установщик 1.1.0](https://github.com/Lizard51/focus-orders/releases/download/v1.1.0/Focus-Orders-Setup-1.1.0.exe), откройте `Focus-Orders-Setup-1.1.0.exe` и выберите папку установки. Он создаст ярлыки на рабочем столе и в меню «Пуск». Требуется Windows 10/11 x64; Python и средства разработки для запуска не нужны.

Если программа уже установлена, сначала экспортируйте базу через «Резервные копии», закройте приложение и установите новую версию в ту же папку поверх прежней. Удалять старую программу или рабочую базу не нужно: данные находятся отдельно. Версия 1.1.0 читает старые заказы и сохраняет их названия; прежняя программа не поддерживает новые поля, поэтому после обновления не открывайте обновлённую базу в 1.0.x.

1. Нажмите «Новый заказ», задайте номер заказа и цифры в поле «Блок», выберите шаблон. Введите `445` — приложение покажет «Блок 445». Старые названия заказов сохраняются; кнопка «Номер и блок» позволяет явно заменить их блоком.
2. Проверяйте пункты, редактируйте текст, добавляйте свои разделы и строки. В «Параметрах» при добавлении раздела выбирайте «Таблица параметров» или «Список с галочками».
3. Открывайте несколько заказов во вкладках. Закрытие вкладки не удаляет заказ. Ввод сохраняется автоматически; результат виден внизу окна.
4. «Завершить заказ» переносит его в архив для просмотра. «Вернуть в работу» сохраняет все данные и разрешает редактирование.
5. Во вкладке «Шаблоны заказов» создавайте именованные шаблоны. Их изменения применяются только к будущим заказам.
6. Во вкладке «Резервные копии» экспортируйте всю базу в JSON. Старые «Данные» можно вставить в поле или открыть из файла. Предпросмотр показывает состав; подтверждение заменяет всю базу, предварительно сохраняя её копию.

Вкладки «Проверка», «Параметры», «Вопросы», «Заметки» перетаскиваются мышкой. Разделы и строки перетаскивайте за ручку с точками слева. Разделы перемещаются только внутри вкладки, строки только внутри раздела. С клавиатуры: установите фокус на ручку и нажмите ↑/↓; на вкладке нажмите Alt+←/→. Порядок сохраняется индивидуально в заказе или шаблоне. Архив доступен только для просмотра.

Вопросы автоматически нумеруются подряд по всем непустым строкам всех разделов. Пустые вопросы не занимают номер. После перестановки/добавления/удаления номера обновляются. «Копировать нерешённые вопросы» копирует номера и полный текст; решённые исключаются, поэтому номера в скопированном списке могут иметь пропуски, совпадая с экраном.

В таблице параметров ↑/↓ переходят в соседнюю строку того же столбца. На начале значения ← переводит в название параметра, на конце названия → переводит в значение. Внутри текста ←/→ продолжают двигать курсор; Shift со стрелками выделяет текст как обычно.

«Поиск заказов» слева ищет по номеру, блоку или прежнему названию в текущем списке «Активные»/«Архив». Можно вводить часть текста без учёта регистра. Очистите поле, чтобы вернуть весь список. Поиск не закрывает открытые вкладки.

При ошибке записи неподтверждённый ввод остаётся в окне. Нажмите «Повторить сохранение». При закрытии приложение предложит остаться, если сохранить не удалось.

Для удаления откройте заказ в активных или архиве, нажмите «Удалить заказ» справа вверху и подтвердите номер. Отмена оставляет заказ в базе. Перед удалением сохраняется резервная копия; восстановление этой копии заменяет всю базу, отдельной корзины нет. Другие заказы и шаблоны при удалении не меняются.

Рабочая база находится в `%APPDATA%\FocusOrders`, отдельно от установки. «Папка данных» открывает этот каталог. Там `state.json` и последние 30 автоматических снимков в `backups`. Храните ручные копии на другом диске для защиты от поломки диска.

Установщик не подписан цифровым сертификатом. Реакцию антивируса/SmartScreen на компьютере получателя нужно проверять там; локальная сборка её не гарантирует. Тестовые заказы из скриншотов в установщик не включены: первый запуск создаёт пустой список и начальный шаблон из исходного HTML.
